    About the Methodology

    Interpretable models for liver fibrosis classification.

    GLOBAL · Decision Tree + LDAExtraTreeClassifier with features derived from clinical markers.
    InputsAGE · AST · ALT · PL
    ClassesG1 (F0–F1) / G2 (F2–F4)
    Models5 datasets × 2 methods
    ProcessingIn your browser

    Standard FIB-4

    FIB-4 = age × AST / (platelet count × √ALT). The displayed index uses the standard formula.

    Interpretation

    The tool distinguishes G1 from G2; it does not assign an individual METAVIR stage. Results do not replace medical evaluation, elastography, or other diagnostic tests.

    Privacy and Hosting

    Predictions run entirely in your browser. Entered values are not sent to an API. Avoid entering identifiable information. To embed this tool in Google Sites, host these files on GitHub Pages and select Insert → Embed.
